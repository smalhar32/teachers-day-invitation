# 🎓 Teachers' Day 2026 — Digital Invitation

A digital invitation website designed with love and gratitude for the teachers of **SAGES Nikum** for Teachers' Day on **5 September 2026**.

## 🌟 Features
- **Cinematic Entrance**: Smooth preloader, animated stars, and deep space aesthetics.
- **Interactive Mystery Gifts**: Interactive gift boxes that reveal heartfelt messages and sound effects.
- **Save the Date & Calendar Integration**: 1-click **Add to Google Calendar** for the event.
- **Social Sharing**: Built-in Web Share API and link copying with toast notifications.
- **Celebratory Confetti**: Interactive celebration animation with dynamic colors, shapes, and audio chime.
- **Fully Responsive**: Optimized for smartphones, tablets, and desktop displays.
